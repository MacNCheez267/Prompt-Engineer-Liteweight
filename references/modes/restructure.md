# Restructure mode

Reorder and group existing instructions to make them easier to follow. Use headings or lists when they clarify relationships. Keep every requirement and its strength intact; do not add missing information or rewrite the task into a different one. Make only light wording edits needed for flow.

## Example

**Before**

> Give me a 5-item list. It should help new gardeners. Cover watering. Use simple language. Don't include equipment.

**After**

> Create a five-item list for new gardeners.
>
> - Cover watering.
> - Use simple language.
> - Do not include equipment.

The revision groups the audience and format first, then lists the existing content and constraints.
