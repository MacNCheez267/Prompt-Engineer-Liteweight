# RTF framework

## Components

- **Role:** A useful perspective or expertise for the task.
- **Task:** The specific action requested.
- **Format:** The expected shape of the result.

## When to use

Use RTF for simple, focused prompts where role, task, and format are enough to make the expected result clear. Prefer it when a larger framework would add length without improving the instruction.

## How to adapt

A role is optional when it does not help. Keep the task direct and make the format as specific as the user requested. Do not invent either. Add context or constraints outside the three headings only when they are genuinely needed; if several such requirements appear, consider RTCCO instead.
